# 面试题记录

本目录用于整理与本仓库学习路线相关的**面试题与答题笔记**，与 `docs/` 正文、`exercises/` 练习分离。

## 建议用法

1. 按主题新建 Markdown（一题一篇，或一主题一篇均可）
2. 每篇尽量写清：**题目 → 考点 → 参考答案 / 口述提纲 → 踩坑**
3. 能关联到学习章节时，链回 `docs/` 对应文件

## 建议命名

```
interview/
  python-oop.md
  asyncio-event-loop.md
  fastapi-dependency.md
  rag-chunking.md
  agent-tool-calling.md
  ...
```

也可按模块分子目录，例如 `interview/02-advanced-python/`，与 `docs/` 编号对齐。
