# 练习：Agent 系统设计

> 对应章节：[`docs/12-agent-production/04-system-design.md`](../../docs/12-agent-production/04-system-design.md)  
> 建议时间：90～120 分钟  
> 难度：★★★★★

## 目标

输出一份可评审的系统设计文档（不必写全量代码）。

## 任务清单

### A. 场景假设（必做）

选定一个场景，例如：

- 内部知识库问答 Bot
- 带工具的客服辅助 Agent
- 代码库问答 + 只读工具

写清：用户是谁、SLA、日请求量粗估、是否允许异步。

### B. 架构图（必做）

在 `playground/12-agent-production/system-design/architecture.md` 用 ASCII/Mermaid 画出：

Client → API →（同步/异步）→ Agent Runtime → LLM/Tools/RAG → 存储 → 观测

标注同步与异步路径。

### C. 关键设计决策（必做）

用表格写至少 6 条决策，例如：

| 决策点 | 选择 | 理由 | 风险 |
|--------|------|------|------|
| 长任务 | 队列 Job | … | … |

必须覆盖：超时、降级、鉴权、成本、评测、日志脱敏。

### D. 失败剧本（必做）

列出 5 个故障场景及应对（LLM 宕机、向量库慢、工具 500、注入攻击、费用突增）。

### E. 演进路线（建议）

画出 3 个月：MVP → 可观测可评测 → 平台化雏形。

## 验收标准

- [ ] 有明确场景与非功能需求
- [ ] 有架构图与同步/异步边界
- [ ] 有决策表与失败剧本
- [ ] 同学/自己能按文档做实现拆分

## 提示

- 这是「设计表达」练习，比堆代码更重要
- 可复用你在 Project 5/6 中的真实实现做对照
