## 基础题（必做）

### B1. 进程信息

写脚本打印：`pid`、`cwd`、`python` 可执行路径（`sys.executable`）。运行两次，观察 pid 变化，写进笔记。

### B2. 阻塞直觉

写函数 `sleep_n(seconds)`，主流程串行调用两次各 0.3s，打印总耗时。  
再在笔记写一句：这两秒里 CPU 大概在忙算还是在等。

### B3. 文件句柄与 with

用 `with` 写文件再读回。再写一段「错误示范注释版」：说明若中途异常且不用 with，可能发生什么（不必真制造泄漏）。

### B4. Agent 内存风险清单（书面）

列出 3 个会导致 Agent 内存涨的做法，并各给一个缓解措施。
